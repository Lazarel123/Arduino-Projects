    Ultrasonic

    Arduino Ultrasonic Distance Measurement

    This project demonstrates how to use an Ultrasonic Sensor (HC-SR04) with Arduino to measure the distance of an object. The sensor sends out an ultrasonic pulse and measures how long it takes for the echo to return — allowing you to calculate how far away an object is.

    1. Basic Concept

    An ultrasonic sensor measures distance using sound waves. It emits a short ultrasonic pulse from the TRIG pin and waits for the reflection (echo) to return to the ECHO pin. By calculating the time difference, the Arduino can determine the distance between the sensor and the object.

    2. Working Principle

    The TRIG pin sends a short 10-microsecond pulse to start the measurement.

    The ECHO pin receives the reflected sound wave (echo) from the object.

    The Arduino measures how long the echo pin stays HIGH (time of flight).

    Using the speed of sound (≈ 0.034 cm/µs), Arduino calculates the distance:

    Distance (cm) = Duration × 0.034 2 Distance (cm)= 2 Duration×0.034 ​

    The division by 2 accounts for the signal traveling to the object and back.

    3. Main Components

    Component Function
    Arduino Board Sends and receives signals to calculate distance.
    Ultrasonic Sensor (HC-SR04) Measures distance by using sound wave reflection.
    Jumper Wires Connect the sensor to the Arduino pins.
    Breadboard Simplifies wiring connections.
    USB Cable Powers the Arduino and allows serial data viewing on your computer.

    4. Circuit Connection

    Ultrasonic Sensor Pin Arduino Pin Description
    VCC 5V Powers the ultrasonic sensor.
    GND GND Common ground with Arduino.
    TRIG D9 Sends the trigger pulse to start measurement.
    ECHO D10 Receives the reflected echo signal.

    Example Code: Basic Ultrasonic Distance Reading

    #define TRIG_PIN 9   // The TRIG pin of the sensor is connected to Arduino pin 9
#define ECHO_PIN 10  // The ECHO pin of the sensor is connected to Arduino pin 10

void setup() {
  Serial.begin(9600);        // Start serial communication at 9600 bps to view data in Serial Monitor
  pinMode(TRIG_PIN, OUTPUT); // Set TRIG pin as output (to send the signal)
  pinMode(ECHO_PIN, INPUT);  // Set ECHO pin as input (to receive the reflected signal)
}

void loop() {
  long duration;  // Variable to store the time the echo signal lasts
  float distance; // Variable to store the calculated distance in centimeters

  // Send a 10 microsecond pulse from TRIG to start the measurement
  digitalWrite(TRIG_PIN, LOW);      // Ensure TRIG is initially LOW (0V)
  delayMicroseconds(2);             // Wait for 2 microseconds
  digitalWrite(TRIG_PIN, HIGH);     // Set TRIG HIGH (5V)
  delayMicroseconds(10);            // Keep it HIGH for 10 microseconds
  digitalWrite(TRIG_PIN, LOW);      // Set TRIG back to LOW (0V)

  // Measure how long the ECHO pin stays HIGH (the time it takes for the sound to return)
  duration = pulseIn(ECHO_PIN, HIGH);

  // Calculate the distance in centimeters
  // Speed of sound ≈ 0.034 cm per microsecond
  // Divide by 2 because the signal travels to the object and back
  distance = duration * 0.034 / 2;

  // Display the distance in the Serial Monitor
  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");

  delay(500); // Wait half a second before the next measurement
}
